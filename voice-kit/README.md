# ชุดโคลนเสียงไทย (รันบนคอมที่มีการ์ดจอ NVIDIA)

> ยังไม่ได้ทดสอบบน GPU/Windows จริง (ทดสอบแล้วบน CPU) ถ้าติดปัญหาให้ส่งข้อความ error มา

## ติดตั้ง (ครั้งเดียว)
1. ติดตั้ง Python 3.11 และ ffmpeg
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install torch==2.4.0+cu124 torchaudio==2.4.0+cu124 --extra-index-url https://download.pytorch.org/whl/cu124
   pip install -r requirements.txt
   ```

## เตรียมเสียงต้นแบบ (ใช้ไฟล์ Recording_2.m4a ของคุณ)
```
ffmpeg -i Recording_2.m4a -ac 1 -ar 24000 -ss 38.82 -to 46.99 ref.wav
```
ข้อความที่พูดในไฟล์นี้ (ใช้เป็น --ref-text):
`ผลประชุมนัดพิเศษบอร์ดการบินไทย มีมติสั่งพักงานเชียวชาย เอี่ยมสิริ พร้อมตั้งสำเนียง อดีตมือ`

## สร้างเสียง
เขียนประโยคลงไฟล์ `lines.txt` (1 บรรทัด = 1 ประโยค สั้นๆ) แล้วรัน:
```
python speak_batch.py --ref ref.wav --ref-text "ผลประชุมนัดพิเศษบอร์ดการบินไทย มีมติสั่งพักงานเชียวชาย เอี่ยมสิริ พร้อมตั้งสำเนียง อดีตมือ" --script lines.txt --outdir out
```
ได้ไฟล์ `out/001.wav, 002.wav, ...` สคริปต์ตรวจแต่ละประโยคเอง ถ้าผิดจะสร้างซ้ำด้วยความเร็วอื่น
- อยากเร็วขึ้นอีก: เพิ่ม `--steps 16`
- คำไหนยังเพี้ยน: เว้นวรรครอบคำนั้นหรือเขียนคำอ่าน

## ความเป็นส่วนตัว
อย่า commit ไฟล์เสียงของคุณ (`ref.wav`, `out/`) ขึ้น GitHub สาธารณะ

## ลดเสียงอู้/ก้องบวม
- สคริปต์ปรับโทนเสียงเบาๆ ให้อัตโนมัติ (ลดย่านอู้ ~300 Hz, ตัดเสียงต่ำสุด) ไม่ใช้ gate/compressor จึงยังเป็นธรรมชาติ ปิดได้ด้วย `--no-polish`
- เสียงต้นแบบควรปรับโทนก่อน (อย่าใช้ตัวลดเสียงรบกวนแบบ AI เพราะทำให้อู้ขึ้น):
  `ffmpeg -i ref.wav -af "highpass=f=100,equalizer=f=300:t=q:w=0.8:g=-4,equalizer=f=650:t=q:w=1:g=-3,equalizer=f=4000:t=q:w=0.7:g=4,loudnorm=I=-18:TP=-2" -ar 24000 ref_clean.wav`
- เสียงสะท้อนห้องในเสียงต้นแบบ โมเดลจะลอกมาด้วย วิธีแก้จริงคืออัดเสียงต้นแบบใหม่ในห้องที่เก็บเสียง (ห้องนอน/ในตู้เสื้อผ้า/ใต้ผ้าห่ม) ใกล้ไมค์ 10-15 ซม.
